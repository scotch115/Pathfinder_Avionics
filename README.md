## Overview
The Pathfinder rocket is a small-to-mid sized model rocket with a custom avionics system that can control liftoff timing and perform rotation corrections during flight.

*This project is still very much a "work in progress", as time is a scare resource these days, so development happens when it can. Seeking to learn new skills and gain
a better understanding of electrical and computer engineering is the primary drive behind this project; sometimes that causes year-long tangents that put this on standby,
but the end result will likely be of a higher quality. Also, the avionics system has to be perfect before I can start building the airframe and attempting to actually
launch this (self-inflicted constraint). As a systems engineer, this is also supposed to feel like a hobby, so whenever it feels like "work", I end up pivoting to a
different personal project.*
